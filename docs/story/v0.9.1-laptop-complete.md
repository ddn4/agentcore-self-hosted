## Gaps found and fixed

1. **Bare `temporal` commands in the docs ignored the repo's profiles.** v0.7's
   `temporal worker deployment describe-version …` failed with an OAuth `invalid_grant`
   (the CLI fell back to the user's own default profile, a Temporal Cloud login), and
   v0.9's `export TEMPORAL_PROFILE=kind; temporal operator namespace list` failed with
   `unable to find profile kind in config data`. Make targets export
   `TEMPORAL_CONFIG_FILE`; a shell does not. Fix: `make env` + `eval "$(make -s env)"` in
   the README and both story docs.
2. **WCI path right after path A.** Starting path B within ~20 s of lifetime 2 means the
   Worker is still polling; the WCI's first invocation is answered "worker already
   polling" and `wci-history` shows 0 `InvokeWorker`. Not a bug (the Worker served the
   conversation), but confusing on stage. Fix: wait for `Healthy` first (README, v0.7 story).
