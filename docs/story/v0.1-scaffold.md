# v0.1-scaffold: a repo you can trust

**Goal.** An empty but green repo with the full harness, a two-namespace dev
server, and proof that Opus 5.5 answers.

**Why now.** "Green at every tag" can only be enforced if `make check` exists
before the first line of agent code, and pre-release software (Serverless
Workers, the Strands plugin) needs its versions recorded on day one.

## Which samples and docs it follows

- **temporal-developer skill** (`references/python/python.md`, `testing.md`,
  `gotchas.md`, `core/dev-management.md`): `ClientConfig.load_client_connect_config()`
  + `setdefault("target_host", ...)` for connections; workflows and activities in
  separate files with pass-through imports; a shared `start_local` environment and
  `start_time_skipping` only per test; mocked Activity by name in the workflow test;
  unique task queue and workflow ID per test; dev-server flags (`--namespace`
  repeatable, `--db-filename`, `--ui-port`, `--ip`).
- **samples-python**
  - `strands_plugin/hello_world/run_worker.py`: Worker shape (`StrandsPlugin` on
    the client, `Worker(client, task_queue=..., workflows=[...])`).
  - `env_config/load_profile.py` + `config.toml`: named profile from a TOML file,
    programmatic defaults after loading.
  - `bedrock_agentcore/strands_agent/pyproject.toml`: dependency set
    (`temporalio>=1.34.0,<2`, `temporalio-strands-agents>=0.1.0`,
    `strands-agents>=1.39.0`, `bedrock-agentcore>=1.9.1`) and hatchling build.
  - `tests/conftest.py`: session-scoped `WorkflowEnvironment` fixture and the
    `dev_server_download_version="v…"` string format used as our fallback.
  - `hello_nexus/README.md`: two namespaces and an endpoint per caller/handler
    (the names follow ADR-0004; the endpoint itself arrives in v0.4).
- **Temporal docs** (via the docs MCP): *Client environment configuration
  reference* (TOML keys, `TEMPORAL_CONFIG_FILE`, `TEMPORAL_PROFILE`, TLS env names);
  *Python Temporal Client* (envconfig precedence); *Strands Agents integration*
  (package `temporalio-strands-agents`, import path `temporalio.strands_agents`,
  `models=` mapping and `model=` per agent).
- **Installed source** checked where docs were thin:
  `temporalio/envconfig.py` (`load_client_connect_config` signature; namespace is
  only returned when set), `temporalio/testing/_workflow.py` (`start_local`
  `dev_server_existing_path`, `connect_client`), `temporalio/strands_agents/_plugin.py`
  (default `BedrockModel` factory with `retries={"max_attempts": 0}`).

## Decisions and deviations

- **ADR-0004 Nexus backing:** standalone-Activity backing is descoped (user
  confirmed); Workflow-backed only.
- **ADR-0007** written now (plan assigns it to v0.9's exercise); it records option
  (c) and the "not in Terraform state" rules before any infra exists.
- **`.tool-versions`** pins `nodejs lts` rather than `20.12+`: asdf fails hard on a
  pinned version that is not installed (it broke `pyright`'s Node shim). Terraform
  is added when `infra/` lands (v0.10).
- **Model factory** uses `os.environ.get(..., default)` rather than
  `os.environ[...]`, so code defaults sit at the bottom of the precedence chain
  (plan §3.2), and adds the plugin's no-retry botocore config (ADR-0001). No
  effort field yet: verified in v0.2.
- **`config/temporal.toml`** sets no namespace in `local`: each service defaults to
  its own namespace in code, so one profile serves both teams; CLI calls pass
  `--namespace`.
- **`make dev`** runs honcho with only the dev server for now; workers join in v0.2–v0.6.
- **`infra-static`** is a no-op until `deploy/` (v0.9) and `infra/` (v0.10) exist.
- **No remote:** plan §3.5's PR/`gh release` steps are skipped; work is on `main`.
