# v0.13-scale-to-zero: Support's compute is gone while a human decides; a second session finishes the reply

**Goal (plan v0.13).** Case B entirely in the cloud. Support runs on AgentCore (the serverless
version `support-supervisor:4ee7f87` from v0.12) and Finance runs on EKS.
1. Finance reaches `input-required`, and Support's AgentCore session drains.
2. The approval arrives, and the Nexus completion creates a Workflow Task.
3. The server's Worker Controller (WCI) makes a **second** `InvokeAgentRuntime`.
4. Session #2 finishes the reply.

The tag also covers the reject variant, the merged timeline, `make e2e` with WCI invocation
counts, the N=10 load test, the Agent Card and compute config in the UI, AWS Q8 and the
re-invoke cadence after a terminate.

**Result (2026-10-31): done.** `scripts/verify/v0.13-scale-to-zero.sh` → `verify: OK` (run
20:53–21:16 UTC; `make check` ran separately just before it and was green, 342 passed).
**Q15 is answered: yes.** The approval's Nexus completion woke the WCI in 26 ms. It invoked
AgentCore 57 ms after the completion, and the new session ran its first Workflow Task 5.7 s
after the completion. This tag creates **no AWS resources**. The Build ID is unchanged
(`4ee7f87`), and everything is **left running** (list and costs below).

## Pause / tear down (not run; the foundation stays up for v1.0)

- **Stop Support from ever starting a session:** `temporal worker deployment set-current-version
  -n agents --deployment-name support-supervisor --unversioned --yes` (sessions only start on demand anyway).
- **Pause the expensive parts:** `make pause` (nodes to 0, RDS stopped; EKS, NAT, endpoints and the NLB
  keep billing, about $0.28/h ≈ $7/day per the v0.10 story). `make resume` brings them back.
- **Tear down in Phase 11 order** (v1.0 will wrap it as `make down`): `set-current-version
  --unversioned` → `delete-version --skip-drainage` → Helm `workercontroller.enabled=false` →
  `temporal operator nexus endpoint delete --name finance-agent` → `make agentcore-down` →
  `make invoke-role-delete` → `helm uninstall temporal` (the LBC removes the NLB) → `kubectl delete ns
  temporal-workers temporal` → `make tf-destroy STACK=30-agentcore-iam` → `STACK=20-platform`
  (final RDS snapshot) → wait for the AgentCore ENIs (up to 8 h) → `STACK=10-network` → delete
  the secrets with a recovery window.

Rollback of this tag: nothing to undo in AWS. To go back to the v0.12 code, revert the
commits: the demo scripts are additive, and `case-b.sh` keeps its laptop behaviour when
`TEMPORAL_PROFILE` is not `eks-pf`.
