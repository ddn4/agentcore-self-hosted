## What it fixed

- `spikes/opus_params.py` reported FAILED on a passing run: it looked for `modelId` in the
  request body, but Converse carries the model ID in the URL path. It now checks the URL.
- `spikes/nested_agents.py` hung at HEAD: since v0.5 the Supervisor always calls Finance over
  Nexus, and the spike's server has no `finance-agent` endpoint, so the first Workflow task
  fails forever. It now exits 2 with a message (it is a v0.3-checkout spike); dropped from
  `make spikes`. Q20 live coverage is the live Case A/B histories (sub-agents attributed).
- `test_live_a2a.py::test_live_case_b_is_escalated` hung at HEAD: written at v0.5, it never
  approved, and since v0.6 the stub Finance waits for a human (the time-skipping server does
  not skip time while a Nexus operation is open, ledger 56). Now
  `test_live_case_b_waits_for_the_approver` signals `approve` and checks `R-STUB-2077`.

## Verify scripts are snapshots of their tags

`scripts/verify/v0.4-finance-agent.sh` and `v0.5-a2a-over-nexus.sh` expect Case B to be
*rejected* (the pre-v0.6 rule), so at HEAD they wait or fail at that step. As with v0.2 and
v0.3, run them from their own tag (`git worktree add ../v05 v0.5-a2a-over-nexus`). Their live
behaviour at HEAD is covered by the v0.6 script, the hand-run Case A/B and `make test-live`.
